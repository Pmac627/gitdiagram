## Active work

The private-fork effort is tracked in [`plans/private-fork.md`](plans/private-fork.md). Before you change code on `feat/private-fork`:

1. Read the tracker: the decisions, the phase checklist and the handoff log.
2. Work on the next unchecked step. Do not reopen decisions the tracker records.
3. Before you stop, update the checkboxes and add a handoff log line.

Do not commit, push or merge. The operator does that.
