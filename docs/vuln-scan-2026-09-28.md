## Detailed findings

### VULN-001: OpenAI key can go to OpenRouter

The dialog identifies the saved credential as an OpenAI API key in `src/components/api-key-dialog.tsx:24`.
The server selects `AI_PROVIDER` independently in `src/server/generate/model-config.ts:15`.
`createClient` in `src/server/generate/openai.ts:48` uses `https://openrouter.ai/api/v1` for OpenRouter.
`resolveApiKey` in `src/server/generate/openai.ts:86` selects the visitor key before the server key.
When the host selects OpenRouter, this path sends a visitor's OpenAI key to OpenRouter as a bearer credential.
OpenRouter can reject authentication after it gets the key.

### VULN-002: Anonymous visitors can spend host model quota

`admitGenerationRequest` in `src/server/generate/request-admission.ts:65` does not make an account necessary.
`resolveApiKey` in `src/server/generate/openai.ts:86` uses the host key when the visitor supplies no key.
The rate limit decreases traffic, but anonymous visitors can use the instance.
This risk applies when the host sets a model key and gives public network access to the service.

### VULN-003: PostHog receives full URLs and replay data

`getPostHog` in `src/lib/analytics-client.ts:39` starts when the host supplies `NEXT_PUBLIC_POSTHOG_KEY` before compilation.
The code lets PostHog record session replay, clicks, submissions, heatmaps, performance data, and uncaught errors.
`PostHogPageviewTracker` in `src/app/providers.tsx:13` sends the full URL with its query string.
The browser sends data to `/phx9a`, and `rewrites` in `next.config.js:118` forwards it to PostHog US endpoints.
Input and network data protection decreases exposure, but page URLs and page content can contain sensitive data.

### VULN-004: Source excerpts can contain secrets

`isArchitectureSource` in `src/server/generate/repository-context.ts:21` does not use files with sensitive names.
The file name filter does not examine ordinary source files for secret values.
`fetchSourceContext` in `src/server/generate/source-context.ts:129` reads selected files from public and private repositories.
`generateStructuredOutput` in `src/server/generate/openai.ts:407` sends the prompt to the selected model provider.
This flow can disclose credentials embedded in code to OpenAI or OpenRouter.

### VULN-005: Admin revocation can fail during a Redis outage

`verifyAdminSession` in `src/server/admin/operator.ts:136` accepts a signed cookie if Redis gives an unknown generation.
A revoked cookie that did not expire can then get access during a Redis outage.
The cookie must have a valid signature.

## Self-hosting assessment

Code changes are necessary for a deployment with no external services.
`checkReadiness` in `src/server/readiness.ts:24` makes a model key, R2 credentials, and an Upstash REST service necessary.
`getClient` in `src/server/storage/r2.ts:51` sets the storage endpoint to Cloudflare R2.
`createClient` in `src/server/generate/openai.ts:48` sets an OpenRouter endpoint or uses the OpenAI SDK.
The [OpenAI SDK v7.23.0 source](https://github.com/openai/openai-node/blob/v7.23.0/src/client.ts) shows that `OPENAI_BASE_URL` changes its default endpoint.

This endpoint must have a compatible API.
This audit did not make sure that a local model is compatible.
GitHub reads use the GitHub hosts in code.

`getStarCount` in `src/server/github-stars.ts:9` contacts the source project.
Remove or change this function for strict self-host egress.

The worker configuration in `workers/presence/wrangler.jsonc:10` sets `ALLOWED_ORIGINS` and `SITE_ORIGIN` to `gitdiagram.com`.
Change those values for a worker on your own site.
Your own accounts can supply credentials for those services, but each provider gets the data shown above.

For the smallest number of outbound paths, do not set the PostHog and live worker values before compilation.
Keep the two video flags unset, and do not set the sponsor analytics keys.
Give access only to trusted users before you set a host model key.
After deployment tests, use egress rules to let traffic go only to the services you select.
